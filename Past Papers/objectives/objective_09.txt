Objective # 08:
Write a program that uses an array A of size n x m that is allocated dynamically; where n and m are inputs to be taken from the user. The array A is treated as a maze in which a mouse is trying to find its way. A[i][j]=0 indicates that the mouse can step onto the location (i,j) and A[i][j]=1 indicates that the mouse can't step onto the location (i,j). A mouse starts from A[0][0] and has to reach A[n-1][m-1], by passing only through positions that are set to 0. A mouse can move in any of the 8 directions provided that those locations have a 0 and they are valid array entries.

You are required to solve the above problem by mapping the scenario on Graph and find the path from start to end using breadth first search; you need to output the indexes of 2-D array that are covered in the path.

Entries in the array should be filled randomly. Graph should be implemented using adjacency list only.
