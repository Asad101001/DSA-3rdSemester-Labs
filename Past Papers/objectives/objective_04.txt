Objective # 04:
Build a Binary Tree by inserting elements in the same manner as nodes are inserted in the heap i.e. from left to right. Each node should hold a float value.
Given a pointer to the root of a binary tree:
- Given an element x, search if x is present in the tree or not.
- Find the predecessors and successors of x; if x exists.
- Find total number of nodes in the tree.
