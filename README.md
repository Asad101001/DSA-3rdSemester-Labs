Hey there! 👋 Welcome to my DSA survival kit! I've uploaded all my practice programs, weekly lab tasks, home tasks, and solutions to past papers here. I've organized everything week by week so it's easier to navigate and cram before the exams inevitably arrive.

| 🚂 `Week 2 (Intro to Linked Lists)/` | Insertion sort and basic singly linked lists. |
| 🔗 `Week 3 (Doubly & Circularly)/` | The harder linked list variants and deletion logic. |

## 💡 Quick Note
Most of the code here is written in raw, old-school **C-style C++** using `structs`, manual memory management (`malloc`/`free`), and bare-metal pointers. I've intentionally avoided complex OOP (classes) and templates to keep the core logic barebones and easy to understand for exams!
