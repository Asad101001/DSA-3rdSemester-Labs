# DSA 3rd Semester Labs

Hey there! This is my personal repository for the **CS-451 Data Structures & Applications** course. I've uploaded all my practice programs, weekly lab tasks, home tasks, and solutions to past papers here. I've organized everything week by week so it's easier to navigate and review before exams.

## What's Inside

| Path | Contents |
| --- | --- |
| `Week 0 (Intro to C++)/` | Brush up on C++ basics: pointers, functions, arrays, dynamic memory. |
| `Week 1 (Binary & Linear Search - Bubble & Selection Sort)/` | Searching algos and simple sorts. |
| `Week 2 (Insertion Sort & Introduction to Linked Lists)/` | Insertion sort and basic singly linked lists. |
| `Week 3 (Doubly & Circularly Linked Lists - Deleting Nodes in LinkedList)/` | The harder linked list variants and deletion logic. |
| `Week 4 (Introduction to Stack & Queue)/` | Arrays vs Dynamic stacks and queues. |
| `Week 5 (HashTables)/` | Linear/quadratic probing and basic hash tables. |
| `Week 6 (Open & Closed Hashing - Linear and Quadratic Probing)/` | Advanced hashing, chaining, and multi-lists. |
| `Week 7 (Introduction to Binary Search Trees - Merge and Quick Sort)/` | Getting started with BSTs, Merge Sort, and Quick Sort. |
| `Week 8 (BST Node deletion and element searching)/` | Removing nodes from a BST (the tricky part). |
| `Week 9/` | Infix to postfix expressions. |
| `Week 10/` | AVL trees and rotations. |
| `Week 11 (Postfix Evaluation & Expression Trees)/` | Expression trees and postfix math. |
| `Week 12 (Heaps and Heap Sort)/` | Max/Min Heaps and sorting. |
| `Week 13 (Graphs)/` | Graph basics, Adjacency Lists/Matrices, and BFS. |
| `Practice/` | Extra grinds for BST and AVL trees. |
| `Mid Term Prep/` | Scuffed midterm revision code. |
| `Past Papers/` | My manual solutions to past-paper objectives! (Zero OOP, pure structs) |

## Quick Note
Most of the code here is written in raw C-style C++ using `structs`, manual memory management (`malloc`/`free`), and pointers. I've intentionally avoided complex OOP and templates to keep the core logic barebones and easy to understand for exams!
