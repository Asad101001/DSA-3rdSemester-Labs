# DSA 3rd Semester Labs

This repository contains C++ practice programs, lab tasks, home tasks, and past-paper solutions for the **CS-451 Data Structures & Applications** course. The code is organized by weekly topics so each file can be compiled and studied independently.

## Repository Structure

| Path | Contents |
| --- | --- |
| `Week 0 (Intro to C++)/` | C++ basics, pointers, functions, arrays, and dynamic memory examples. |
| `Week 1 (Binary & Linear Search - Bubble & Selection Sort)/` | Linear search, binary search, duplicate search variants, bubble sort, and selection sort. |
| `Week 2 (Insertion Sort & Introduction to Linked Lists)/` | Insertion sort and introductory singly linked list operations. |
| `Week 3 (Doubly & Circularly Linked Lists - Deleting Nodes in LinkedList)/` | Doubly linked lists, circular linked lists, and deletion logic. |
| `Week 4 (Introduction to Stack & Queue)/` | Static and dynamic stack and queue implementations. |
| `Week 5 (HashTables)/` | Linear probing, quadratic probing, templates, and basic hash table implementations. |
| `Week 6 (Open & Closed Hashing - Linear and Quadratic Probing)/` | Open hashing, closed hashing, queues, stacks, linked lists, and multi-list practice. |
| `Week 7 (Introduction to Binary Search Trees - Merge and Quick Sort)/` | Binary search trees plus recursive and non-recursive merge/quick sort practice. |
| `Week 8 (BST Node deletion and element searching)/` | BST deletion and search tasks. |
| `Week 9/` | Infix to postfix conversion. |
| `Week 10/` | AVL tree implementation practice. |
| `Week 11 (Postfix Evaluation & Expression Trees)/` | Postfix evaluation and expression tree construction. |
| `Week 12 (Heaps and Heap Sort)/` | Heap and heap sort implementation. |
| `Week 13 (Graphs)/` | Graph representations and BFS examples. |
| `Practice/` | Extra practice implementations for BST and AVL trees. |
| `Mid Term Prep/` | Midterm preparation code, currently focused on linked lists. |
| `Past Papers/` | Objective-style DSA problem solutions from past papers. |
| `tmp/` | Temporary or experimental files. |

## Topics Covered

- C++ fundamentals: functions, pointers, arrays, and dynamic memory
- Searching: linear search and binary search
- Sorting: bubble sort, selection sort, insertion sort, merge sort, and quick sort
- Linked lists: singly, doubly, circular, recursive traversal, and deletion
- Stacks and queues: static and dynamic implementations
- Hash tables: open hashing, linear probing, and quadratic probing
- Trees: BST, AVL tree, heap tree, expression tree
- Expression processing: infix to postfix and postfix evaluation
- Graphs: adjacency list, adjacency matrix, and breadth-first search
- Past-paper style DSA problem solving
